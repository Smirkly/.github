# Smirkly

Smirkly is a modern messaging platform built around C++20 services powered by the userver framework.

## Repositories

| Repository | Purpose |
|---|---|
| smirkly-auth | Authentication, user accounts, sessions, and account recovery |
| smirkly-chat | Messaging, WebSocket communication, and real-time delivery |
| smirkly-platform | Local orchestration, observability, and service integration |

## Current Status

All Smirkly services are under active development.

## Technology

C++20 · userver · PostgreSQL · Redis · Docker Compose · Prometheus · Grafana
